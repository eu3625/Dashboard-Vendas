# 📊 Dashboard de Vendas

## 1. Sobre o projeto

Dashboard interativo desenvolvido em HTML5, CSS3 e JavaScript para análise e acompanhamento de vendas.

O projeto utiliza uma base de dados com 29 pedidos, permitindo visualizar indicadores, gráficos, relatórios e informações comerciais.

## 2. Tecnologias utilizadas

- HTML5 – Estrutura da página.
- CSS3 – Estilização e layout responsivo.
- JavaScript – Cálculos, filtros e atualização dos gráficos.

## 3. Indicadores principais

O dashboard apresenta:

- Faturamento total.
- Quantidade de pedidos.
- Unidades vendidas.
- Ticket médio.

## 4. Gráficos e análises

O sistema possui:

- Gráfico de faturamento por região.
- Gráfico de faturamento por produto, com legenda.
- Gráfico de evolução das vendas por data.

## 5. Filtros disponíveis

É possível pesquisar e filtrar os pedidos por:

- Data inicial.
- Data final.
- Região.
- Produto.
- Número do pedido.
- Estado.

Os indicadores, gráficos e relatórios são atualizados automaticamente conforme os filtros selecionados.

## 6. Relatórios automáticos

O dashboard apresenta relatórios em tópicos com:

- Região com maior faturamento.
- Produto com maior faturamento.
- Data com maior volume de vendas.
- Ticket médio.
- Quantidade de pedidos e unidades comercializadas.

## 7. Base de dados

O projeto utiliza 29 pedidos registrados entre 17/11/2024 e 21/11/2024.

Faturamento total informado na planilha: **R$ 245.355,00**.

Os dados representam um histórico de vendas, não vendas atuais.

## 8. Como executar

1. Localize o arquivo `Dashboard_Vendas.html`.
2. Dê dois cliques no arquivo.
3. O dashboard será aberto no navegador.
4. Utilize os filtros para analisar os resultados.

Não é necessário instalar programas ou utilizar servidores.

## 9. Objetivo do projeto

Facilitar a visualização e interpretação dos dados comerciais, permitindo acompanhar resultados, identificar produtos de destaque e analisar o desempenho das regiões de vendas.
